# 또봄 보도 모니터링

`naver-news-search` 스킬로 또봄(한국청년암협회) 관련 보도를 수집하고, 팀이 바로 쓸 수 있는
형태로 정리한다. 인자: `$ARGUMENTS`

## 1. 검색

검색어가 주어지지 않았으면 아래 기본 세트를 모두 돌린다.

- `또봄`, `한국청년암협회`, `청년 암 환자`, `AYA 암`, `또봄클래스`, `앎 캠페인`

기간이 없으면 최근 2주로 잡는다. 단체명 `또봄`은 일반 명사와 겹치므로,
청년·암·비영리 맥락이 없는 결과는 걸러낸다.

## 2. 정리

수집 결과를 이렇게 정리한다.

| 날짜 | 매체 | 제목 | 링크 | 한 줄 요약 | 분류 |
|---|---|---|---|---|---|

분류는 `보도자료 반영 / 인터뷰 / 언급 / 무관` 중 하나. `무관`은 표 아래에 개수만 적고 뺀다.

## 3. 산출물 (사용자 확인 후에만 실행)

정리 결과를 보여준 뒤, 무엇을 진행할지 물어본다. **묻기 전에 먼저 실행하지 않는다.**

- **Slack 공유** — 홍보 채널에 올릴 메시지 초안을 만든다. 새 보도 건수, 주목할 기사 3건,
  링크. 채널명을 확인하고, 사용자가 승인하면 Slack MCP 로 전송한다.
- **Notion 기록** — 보도 아카이브 DB에 행을 추가한다. DB 위치를 모르면 먼저 검색해 확인한다.
- **news.html 반영** — 사이트에 실을 만한 보도가 있으면 [news.html](news.html) 의 기존
  카드 마크업 구조를 그대로 따라 추가 패치를 제안한다. 링크는 원문 매체로 걸고,
  환자 신원이 드러나는 표현은 쓰지 않는다.

## 톤 원칙

또봄 콘텐츠 원칙을 따른다 — '다시 봄'의 희망 톤, 투병 클리셰·공포 이미지 배제,
환자 신원 비식별. 자세한 내용은 [README.md](README.md) 참고.
