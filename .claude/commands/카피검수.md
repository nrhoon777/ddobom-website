# 또봄 카피 검수

대상: `$ARGUMENTS`

대상이 비어 있으면 `git diff` 로 이번 작업에서 바뀐 HTML/마크다운의 한국어 텍스트를 뽑아 쓴다.
HTML 이면 태그·속성·스크립트는 빼고 사용자에게 보이는 텍스트만 추출한다.

## 검수 3단계

1. **맞춤법·띄어쓰기** — `korean-spell-check` 스킬. 제안은 보수적으로 다루고,
   또봄 고유명사(또봄, 또봄클래스, 앎 캠페인, Cheer UP, 곧·봄, 위케어리셋, 또또봄TV)는
   오탈자로 잡히더라도 고치지 않는다.
2. **분량** — `korean-character-count` 스킬. 목표 글자수가 주어졌거나 아래 채널 제한에
   해당하면 초과/미달을 표시한다.
   - 메타 디스크립션 80–120자 · 카드 요약 60–90자 · 인스타 캡션 ~1000자
3. **문체** — `korean-humanizer` 스킬. 번역체, AI 상투어, 과도한 명사화·피동을 잡는다.
   목표 글자수가 있으면 그 분량에 맞춰 다시 쓴다.

## 또봄 문체 게이트 (자동 교정이 못 잡는 것)

아래는 직접 확인한다.

- 투병 클리셰(`싸움`, `투쟁`, `극복기`), 공포·동정 유발 표현 → 쓰지 않는다
- 환자 실명·병원명·병기 등 신원이 드러나는 정보 → 비식별 처리
- 후원 요청은 압박이 아니라 초대의 어조로
- 의료 정보를 단정적으로 쓰지 않는다 (진단·치료 효과 주장 금지)

## 출력

파일별로 `원문 → 수정안 → 사유` 표를 만들고, 마지막에 실제 파일에 적용할지 물어본다.
승인 없이 파일을 고치지 않는다.
