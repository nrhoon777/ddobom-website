# 내 메신저로 보내기

`send-to-me` 스킬을 써서 결과물을 사용자 본인의 메신저로 보낸다. 인자: `$ARGUMENTS`

## 1. 무엇을 보낼지 정한다

인자에 본문이 있으면 그것을, 없으면 **직전 대화에서 만든 결과물**(보도 정리표, 카피 검수 결과,
공고 요약, 초안 등)을 대상으로 잡는다. 무엇을 보낼지 모호하면 묻는다.

메신저용으로 다듬는다.

- 마크다운 표 → `· 항목 — 값` 줄글 (메신저에서 표는 정렬이 깨진다)
- 링크는 끝에 모아 붙인다
- 제목 한 줄 + 핵심 3~5줄. 원문 전체가 필요하면 파일로 보내지 말고 링크로 건넨다

## 2. 채널

텔레그램뿐이다. 카카오톡은 설정이 끝나지 않았다(콘솔 개편으로 Redirect URI 등록 위치를
찾지 못해 중단). 사용자가 카톡을 지목하면 텔레그램으로 보내도 되는지 묻는다.

## 3. 확인 (필수)

보낼 본문 전체와 채널, 예상 메시지 개수를 보여주고 **명시적인 승인을 받는다.**
필요하면 `--dry-run` 으로 분할 결과를 먼저 보여준다.

```bash
python3 scripts/notify/send_telegram.py --file <임시파일> --dry-run
```

수혜자 실명·연락처·병력 등 개인정보가 섞였으면 전송 전에 짚고 뺄지 묻는다.

## 4. 전송

```bash
python3 scripts/notify/send_telegram.py --file <임시파일>
```

임시파일은 시스템 임시 디렉터리에 쓰고 저장소에 남기지 않는다.

## 5. 설정 미완료 시

인증 오류가 나면 토큰을 받아 적으려 하지 말고 `INTEGRATIONS.md` 7절 절차를 안내한다.
발급·로그인은 사용자가 직접 한다.
