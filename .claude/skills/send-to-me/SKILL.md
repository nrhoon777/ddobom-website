# send-to-me — 내 텔레그램으로 보내기

작업 결과물(보도 정리, 카피 검수 결과, 공고 요약, 뉴스레터 초안 등)을 사용자 본인의
메신저로 밀어 넣는다. 밖으로 나가는 메시지이므로 **항상 확인을 먼저 받는다.**

**쓸 수 있는 채널은 텔레그램뿐이다.** 카카오톡은 설정이 끝나지 않았다 —
카카오 개발자 콘솔 개편으로 Redirect URI 등록 위치를 찾지 못해 중단했다.
사용자가 "카톡으로 보내줘"라고 하면 **텔레그램으로 보내도 되는지 묻고**, 굳이 카카오를
쓰려면 설정을 다시 해야 한다고 알린다. 임의로 카카오 스크립트를 실행하지 않는다.

## 전송 전 절차 (건너뛰지 말 것)

1. 보낼 본문을 채팅에 그대로 보여준다. 길면 앞 10줄 + 전체 글자수.
2. 채널은 텔레그램이다. 사용자가 카톡을 지목했다면 여기서 짚는다.
3. **사용자가 "보내"라고 답한 뒤에만** 실제 전송 명령을 실행한다.
   먼저 `--dry-run` 으로 분할 결과를 확인시켜도 좋다.
4. 개인정보(수혜자 실명·연락처·병력)가 섞여 있으면 보내기 전에 짚어준다.

사용자가 한 번 승인했다고 다음 전송까지 승인된 것은 아니다. 매번 확인한다.

## 실행

본문은 인자·`--file`·표준입력 셋 중 하나로 넘긴다. 여러 줄이면 파일이나 표준입력이 안전하다.

```bash
python3 scripts/notify/send_telegram.py "오늘 보도 3건 정리했습니다"
python3 scripts/notify/send_telegram.py --file /tmp/보도정리.md
cat /tmp/보고서.md | python3 scripts/notify/send_telegram.py -
```

- 한 통 4,096자 제한이라 스크립트가 3,900자 단위로 나눠 보낸다. 웬만한 보고서는 한 통에 들어간다.
- 마크다운 표는 텔레그램에서도 정렬이 깨진다. 표가 핵심이면 `· 항목 — 값` 줄글로 바꾼다.
- `--html` 로 `<b>`, `<i>`, `<a href>` 서식을 쓸 수 있다.

## 설정이 안 돼 있을 때

"TELEGRAM_BOT_TOKEN 가 없습니다" 로 멈추면 토큰을 대신 받아 적으려 하지 말고
`INTEGRATIONS.md` 7절 절차를 안내한다. 토큰 발급은 사용자가 직접 하는 일이다.
chat_id 만 없다면 `python3 scripts/notify/send_telegram.py --find-chat-id` 로 찾아 넣어준다.

## 관련

텔레그램에서 Claude 를 **부르는** 것까지 하려면 채널 플러그인으로 양방향이 된다 —
`bash scripts/claude-channels.sh telegram`.
