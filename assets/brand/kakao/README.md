# 카카오톡 채널 이미지 (한국청년암협회 또봄)

채널 관리자센터 → 채널 정보 설정에서 올리는 이미지들이다.
모두 로고와 또봄 캐릭터만 썼다. 실제 환우 사진은 초상권 동의서가 정리된 뒤에 쓴다.

| 파일 | 크기 | 쓰는 곳 |
|---|---|---|
| `01-프로필-크림.png` | 640×640 | 프로필 이미지 (기본 추천) |
| `02-프로필-청록.png` | 640×640 | 프로필 이미지 (대화 목록에서 더 눈에 띄는 쪽) |
| `03-채널홈-배경.png` | 800×500 | 배경 이미지. 아래 가운데는 프로필이 겹치므로 비워 두었다 |
| `04-소개카드.png` | 800×800 | 채널 첫 포스트 / 소개 |
| `05-하는일카드.png` | 800×800 | 프로그램 안내 포스트 |

PNG는 실제 크기의 2배(레티나)로 뽑았다. 카카오가 알아서 줄인다.

원본 레이아웃은 HTML로 짰다. 문구를 고칠 일이 생기면 다시 만들면 된다.
바탕색 `#0f8a76`(청록) · `#fdfaf2`(크림), 강조 `#dcff50`(라임)는 홈페이지와 같은 값이다.
