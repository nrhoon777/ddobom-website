## 1. 왜 이렇게 만들었나

기존에 쓰시던 두 가지 사이에 빈 칸이 있었습니다.

| | 하는 일 | 한계 |
|---|---|---|
| **카드뉴스** (1억으로 만드는…) | 널리 뿌리기 | 남의 숫자라 그냥 광고로 읽힘 |
| **개인 제안서** (마르지 않는 우물 2p) | 깊게 설득 | 이미 마음 연 사람에게만. 1명당 1개를 손으로 만들어야 함 |
| **↑ 이 사이트가 채우는 자리** | **본인이 혼자 만져보는 단계** | 아무것도 묻지 않으니 영업이 아님 → 그래서 던질 수 있음 |

설계 원칙 네 가지:

1. **첫 화면에 설명이 없습니다.** 슬라이더 두 개와 큰 숫자뿐입니다.
   손이 먼저 움직여야 "보험 얘기"라는 경계가 안 생깁니다.
2. **파는 숫자가 아니라 검증되는 숫자를 씁니다.** 첫 화면의 답은
   *"원금을 한 푼도 헐지 않고 매달 뽑을 수 있는 금액"* 입니다. 작아 보이지만 계산이 맞고,
   슬라이더를 올리면 "만 ○세에 바닥납니다"로 바뀌어서 오히려 설득력이 큽니다.
3. **결과가 링크에 담깁니다.** 조건이 URL 해시에 저장돼, 받은 사람이 열면 그 화면이 그대로
   보이고 바로 자기 숫자로 바꿔볼 수 있습니다. **지인의 지인까지 가는 유일한 경로**입니다.
4. **연락은 맨 마지막**에, 카톡·문자·폼 세 갈래로. 문자는 계산 조건이 자동으로 담깁니다.

## 3. ⚠️ 기존 제안서의 숫자 하나가 안 맞습니다

`마르지 않는 우물` 2페이지 표의 **'연간 인출액'** 열입니다.

| 자료의 값 | 검증 |
|---|---|
| 62세 연간 인출액 $56,648 | 그 시점 적립금이 $125,910입니다. **2~3년이면 바닥**납니다 |
| 기본생활비 $71,880/년 (월 854만원) | 62세부터 빼면 **만 64세에 0원** |
| 100세 잔액 $543,850 | **"62~71세 매년 $3,000만 빼고 이후 무인출"** 시나리오와 정확히 일치 (재계산 $543,597) |

그래프·잔액·환급률은 전부 맞고 **표의 그 열만** 실제 시나리오와 다릅니다.
원본 설계서에서 그 열이 무엇이었는지 확인해 주세요. (연금 전환 시 연간 수령액이었을 가능성)

## 4. 계산 모델 — 설계서에서 역산했습니다

설계서의 세 지점으로 두 개의 상수를 뽑았고, 그 상수로 세 지점이 모두 재현됩니다.

| 확인점 | 설계서 | 이 사이트 |
|---|---|---|
| 62세 적립금 | $125,910 (124.9%) | $125,904 (124.9%) |
| 71세 (연 $3,000 인출 후) | $152,920 | $152,849 |
| 100세 (이후 무인출) | $543,850 | $543,597 |

```js
WELL.effRate = 4.47   // 실효 적립이율 = 공시 4.72% − 보험비용 약 0.25%p
WELL.credit  = 0.775  // 적립비율 — 사업비·위험보험료 차감 후
```

**원금을 헐지 않는 최대 인출액 = 적립금 × 실효이율 ÷ 12.**
42세 월 $420 20년납 → 62세 적립금 $125,904 → 매달 **$469** (약 65만원).
설계서의 연 $3,000은 이 선의 절반이라 원금이 오히려 불어난 것입니다.

## 6. 아직 못 넣은 것 (주시면 반영합니다)

- **최저보증이율** — 지금 2.50%로 가정해 뒀습니다. `WELL.minRate` <span>확인 필요</span>
- **중도인출 시 사망보험금이 얼마나 줄어드는지** — 3막 '계속 뽑기'에서 문구로만 안내 중
- **연금 개시 나이별 월 수령액** — 지금은 설계서의 75세 개시 $1,289.48을 적립금에 비례
  환산합니다. 55·60·65·70세 표가 있으면 훨씬 정확해집니다
- **여성·다른 연령 기준 수치** — 기준 계약이 42세 여자라 그 외 나이는 근사입니다
- **사망보험금 산출 기준** — 지금은 월납액에 비례(월 $420 → $150,000)로 두었습니다

## 8. 기술 메모

- 순수 HTML + CSS + 바닐라 JS, 빌드 없음. 폴더째 복사하면 어디든 올라갑니다
- 로컬 확인: `python -m http.server 8000` → `http://localhost:8000/well/`
- 조건은 URL 해시(`#a=42&p=420&t=20&s=62&d=45`)에 담기고, 해시만 바뀌어도(뒤로가기·붙여넣기)
  다시 계산합니다
- 웹폰트는 비동기 로드 — 폰트 CDN이 느려도 페이지 기능이 멈추지 않습니다
- 접근성: 스킵링크, `aria-pressed`/`aria-selected`, 44px 이상 터치 영역, `prefers-reduced-motion`
