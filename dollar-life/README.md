# 달러 종신·연금 플랜 — 인터랙티브 상품 안내 페이지

또봄(한국청년암협회) 홈페이지와 **완전히 분리된 단독 랜딩 페이지**입니다.
이 폴더(`dollar-life/`)만 통째로 복사하면 다른 사이트/도메인에도 그대로 올라갑니다.
빌드 도구·프레임워크·외부 라이브러리 없이 HTML + CSS + 바닐라 JS로만 되어 있습니다.

```
dollar-life/
├─ index.html          페이지 전체(마크업)
├─ assets/style.css    디자인 시스템(딥네이비 + 골드)
├─ assets/app.js       인터랙션 + 보험료 시뮬레이션 엔진
└─ README.md           이 문서
```

주소: `https://nrhoon777.github.io/ddobom-website/dollar-life/`

## 2. 실서비스 전에 꼭 바꿔야 할 것

`assets/app.js` 맨 위 `CONFIG` 하나만 고치면 됩니다.

```js
var CONFIG = {
  kakaoUrl: "http://pf.kakao.com/_카카오채널ID/chat", // 카카오톡 채널 상담 링크
  tel: "010-0000-0000",                               // 상담 전화번호
  consultant: "담당 설계사",                            // 표시 이름
  formEndpoint: "",                                   // 폼 수신 URL (비우면 클립보드 방식)
  fxDefault: 1380                                     // 기본 환율 가정
};
```

### 상담 폼 접수 방법
- **`formEndpoint`가 비어 있으면**: 신청 내용을 **클립보드에 복사**하고 카카오톡 채널을 새 창으로 엽니다.
  고객이 붙여넣기만 하면 되므로 서버 없이도 동작합니다. (현재 기본값)
- **`formEndpoint`에 URL을 넣으면**: 해당 주소로 JSON을 POST 합니다.
  `{ text, data:{name,phone,time,way,memo}, sim:{age,sex,prem,term,start} }`
  - 가장 쉬운 방법: [Formspree](https://formspree.io) 무료 엔드포인트 붙여넣기
  - 또는 Google Apps Script 웹앱 / 자체 API

> 개인정보(성함·연락처)를 받는 페이지이므로, 실제 접수 경로를 붙일 때는
> **수집·이용 동의 문구와 실제 보관·파기 절차가 일치하는지** 반드시 확인하세요.

## 3. 시뮬레이션은 "예시 계산"입니다 ⚠️

`assets/app.js`의 계산은 특정 보험사 상품의 실제 요율이 **아닙니다.**
달러 종신보험의 일반적인 구조를 단순화한 **예시 모델**이며, 페이지에도 그렇게 표기되어 있습니다.

| 항목 | 현재 가정 |
|---|---|
| 보험료 요율 | 사망보험금 $1,000당 월 보험료 = `1.30 × e^(0.055×(나이−25))`, 여성 ×0.82 |
| 납입기간 배수 | 10년납 ×1.72 / 15년납 ×1.28 / 20년납 ×1.0 |
| 적립 비율 | 1–2년차 35% · 3–5년차 62% · 6–10년차 75% · 11년차~ 80% |
| 적립이율 | 연 3.0% 월복리 (화면에서 2.0 / 3.0 / 3.5% 전환 가능) |
| 연금 | 20년 확정 지급 |
| 환율 | 1,380원 (결과 화면에서 1,000~1,800원 조작 가능) |

**실제 상품 요율표로 교체하는 법**: `app.js`의 `rate1000()`, `TERM_F`, `CREDIT()` 세 곳만 바꾸면
나머지(차트·연금·손익분기 계산)는 그대로 동작합니다.
정확도가 중요하다면 회사의 가입설계 프로그램에서 뽑은 연령·성별별 요율표를 배열로 넣어 참조하는 방식을 권합니다.

### 환율 차트 데이터
`app.js`의 `FX` 배열은 1995~2025년 **연평균 원/달러 근사치**입니다(참고용 표기).
공식 통계(한국은행 ECOS 등)의 확정치로 교체하는 것을 권장합니다.

## 4. 게시 전 체크리스트

- [ ] `CONFIG` 4개 값(카톡·전화·이름·폼) 교체
- [ ] 요율/적립 가정을 실제 상품 기준으로 교체하거나, "예시"임을 그대로 유지
- [ ] 환율 데이터 확정치로 교체
- [ ] **소속 회사의 광고 심의(준법감시인 심의필) 절차 통과** — 보험 상품 광고는 심의 대상입니다.
      심의필 번호·유효기간을 푸터에 표기해야 하는 경우가 많습니다.
- [ ] 유의사항 문구를 실제 상품 약관·상품설명서 기준으로 재검토
- [ ] 개인정보 수집·이용 동의 문구를 실제 처리 방침과 일치시키기

## 5. 기술 메모

- 반응형: 모바일 우선, 브레이크포인트 620 / 760 / 860 / 900px
- 접근성: 스킵링크, `aria-selected`/`aria-pressed`/`aria-expanded`, 탭 키보드 좌우 이동,
  44px 이상 터치 영역, `prefers-reduced-motion` 대응, 라이브 리전으로 단계 안내
- 차트는 전부 **런타임에 SVG로 그림** (이미지·라이브러리 없음)
- 로컬 확인:
  ```bash
  python -m http.server 8000
  # http://localhost:8000/dollar-life/
  ```
