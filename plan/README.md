# 달러 플랜 — 니즈 선택형 달러보험 안내 사이트

또봄(한국청년암협회) 홈페이지와 **완전히 분리된 독립 사이트**입니다.
`plan/` 폴더만 통째로 복사하면 다른 도메인에도 그대로 올라갑니다.
빌드 도구·프레임워크·외부 라이브러리 없이 HTML + CSS + 바닐라 JS로만 되어 있습니다.

주소: `https://nrhoon777.github.io/ddobom-website/plan/`

## 흐름

```
index.html  ── 핵심 메시지 (비과세 5년→7년→10년 / 축소 검토 / 건보료)
            ├─ 근거 기사 3건
            ├─ STEP 1  이 돈, 어떻게 하고 싶으세요?      ← 3택
            └─ STEP 2  조금만 더 좁혀볼게요               ← 2택 (누르면 아래에 펼쳐짐)
                  │
    ┌─────────────┼─────────────────┐
    ▼             ▼                 ▼
 grow.html    income.html      protect.html
  ?m=short     ?m=now           ?m=health
  ?m=long      ?m=later         ?m=legacy
```

| 페이지 | 보여주는 것 |
|---|---|
| `grow.html?m=short` | 목표 금액까지 매달(또는 일시납) 얼마씩 넣어야 하는지 **역산** |
| `grow.html?m=long` | 10·15·20·30년 뒤 달러 금액과 환급률, 낸 돈을 넘어서는 시점 |
| `income.html?m=now` | 목돈을 넣고 **다음 달부터** 매월 수령. 원금은 그대로 유지 |
| `income.html?m=later` | 15~20년 뒤부터 매월 수령. 받는 동안에도 원금이 유지되는 그래프 + 중도인출 시뮬 |
| `protect.html?m=health` | 금융소득에서 얼마가 빠지는지, 기준선(1천/2천만원) 아래로 가려면 얼마를 옮겨야 하는지 |
| `protect.html?m=legacy` | 물려줄 수 있는 달러 금액과 배수 |

모든 결과 페이지에 **뒤로 / 처음부터 다시** 버튼, 헤더에 **문자·상담** 버튼이 상시 노출됩니다.

## 설계에 반영한 원칙

- **여러 상품을 한꺼번에 보여주지 않습니다.** 두 번 고르면 한 가지 이야기만 남습니다.
- **달러 금액이 주인공, 원화는 보조.** 환율 슬라이더를 움직이면 달러 금액은 그대로이고
  **원화만** 바뀝니다 — 환차익이 눈으로 보입니다. (납입액은 가입 시점 환율로 달러 고정)
- **매월 15일 기준**이라는 점을 모든 결과 페이지 상단 배지와 유의사항에 못 박았습니다.
  "정확한 수치는 만나서"가 자연스러운 다음 단계가 되도록 상담 섹션 문구를 맞췄습니다.
- **비과세 한도를 실시간으로 판정합니다.** 월납 150만원 / 일시납 1억을 넘으면 경고와 함께
  "종신형 연금으로 개시하면 한도 없음"을 안내합니다.
- **자유 입출금**을 첫 화면과 income 페이지에서 직접 조작해볼 수 있게 했습니다.

## 1. 지금 바로 바꿔야 할 것 — `assets/data.js` 맨 위

```js
var CONFIG = {
  consultant: "담당 설계사",
  tel:        "010-0000-0000",     // 전화 + 문자 수신 번호 (문자 버튼이 이 번호로 보냅니다)
  kakaoUrl:   "http://pf.kakao.com/_카카오채널ID/chat",
  formEndpoint: "",                // Formspree 주소 (권장)
  email:        "",
  asOf: "2026-08-15",              // 공시이율 기준일 — 매월 갱신할 때 같이 바꿉니다
  fx:   { now: 1385, min: 1150, max: 1650 }
};
```

**신청 폼을 메일로 받는 법 (셋 중 하나)**

| 방법 | 설정 | 동작 |
|---|---|---|
| **① Formspree (권장)** | `formEndpoint: "https://formspree.io/f/xxxxxxx"` | 제출하면 **메일함으로 바로 도착**. 페이지에 메일 주소가 노출되지 않음 |
| ② 메일 앱 | `email: "myname@gmail.com"` | 고객 메일 앱이 열리고 내용이 자동으로 채워짐 |
| ③ 카카오톡 (현재 기본) | 둘 다 비움 | 신청 내용이 클립보드에 복사되고 카카오톡 채널이 열림 |

②는 소스에 메일 주소가 남아 **스팸 수집 대상**이 됩니다. ①을 권합니다.

## 2. ★ 아직 못 받은 것 — 상품 데이터

지금 계산에 쓰이는 숫자는 **전부 예시값**입니다. 아래를 주시면 그대로 반영합니다.

### (1) 달러 상품 라인업 — 아직 첨부되지 않았습니다
말씀하신 첨부파일이 대화에 들어오지 않았습니다. 다시 올려주시면 `LINEUP.items` 에 넣고,
세 갈래(불리기 / 매달 받기 / 지키기)에 어떤 상품이 맞는지 매칭해 드리겠습니다.

### (2) 계산 기준 — 이것만 있으면 숫자가 진짜가 됩니다

```js
BASE.rate = { current: 4.5, min: 2.5, options: [2.5, 3.5, 4.5, 5.5] }   // 달러 공시이율 / 최저보증
BASE.payout.rate = 4.5        // 즉시 월지급형 연 지급률 (원금 유지형)
BASE.annuity  = { months: 240, startAges: [55, 60, 65, 70] }
BASE.withdraw = { maxPct: 50, freeCount: 12, fee: 0 }   // 중도인출 한도·횟수·수수료
BASE.addPay   = { maxRatio: 2 }                          // 추가납입 한도 (기본보험료의 N배)
BASE.bankRate = 3.0           // 비교용 예금 금리 (건보료 계산의 '그대로 뒀을 때' 가정)
```

### (3) 가장 중요 — 경과 연차별 **환급률 표**
가입설계서 뒤쪽 "해지환급금 예시표"를 그대로 옮기면 추정 모델 대신 이 표가 계산 기준이 됩니다.

```js
BASE.refund = {
  10: { 3: 78.2, 5: 91.0, 7: 104.5, 10: 118.3, 15: 141.0, 20: 168.5, 30: 240.1 },  // 10년납
  20: { 3: 80.1, 5: 93.4, 7: 106.2, 10: 116.0, 15: 129.5, 20: 146.2, 30: 217.0 }   // 20년납
}
```
환급률(%) = 해지환급금 ÷ 그때까지 낸 보험료 × 100.
표에 없는 연차는 자동 보간, 마지막 연차 이후는 공시이율로 연장합니다.

> **말로 주셔도 됩니다.** "45세 남 월 $500 20년납이면 20년 뒤 환급금 얼마" 식으로
> 대표 케이스 2~3개만 주셔도 그 점에 맞게 모델을 보정할 수 있습니다.
> 여러 회사 상품을 주시면 공통 구간을 뽑아 평균 기준으로 계산하도록 바꾸겠습니다.

### (4) 확인이 필요한 것
- **비과세 요건 문구** — `TAX` 의 일시납 1억 / 월납 150만원 / 유지 10년 / 납입 5년,
  그리고 "종신형 연금 개시 시 한도 없음"의 정확한 요건(개시 연령, 수령 형태 등)
- **중도인출·추가납입**의 실제 한도·횟수·수수료
- `BENEFITS` 각 항목 — 약관으로 확인한 뒤 `confirmed: true` 로 바꾸면 화면의
  **"확인 필요" 배지**가 사라집니다

## 3. 게시 전 체크리스트

- [ ] `CONFIG` 값(이름·전화·카톡·폼/메일·기준일·환율) 교체
- [ ] 라인업 파일 반영 + 환급률 표 입력
- [ ] `BENEFITS` / `TAX` 를 약관·세법으로 확인하고 `confirmed: true`
- [ ] **광고 심의(준법감시인 심의필)** — 보험 상품 광고는 심의 대상입니다.
      특히 아래 두 가지를 심의에서 꼭 확인받으세요:
      - 첫 화면의 **"5년→7년→10년, 지금은 축소 검토"** 문구 (시급성 표현)
      - **언론 기사 인용** (`NEWS` 배열) — 인용 가능 여부. 빼려면 배열을 비우면 됩니다
- [ ] 심의필 번호·유효기간을 푸터에 표기해야 하는지 확인
- [ ] 개인정보 수집·이용 동의 문구를 실제 처리 방침과 일치시키기

## 4. 기술 메모

- 반응형 모바일 우선 / 브레이크포인트 620·760·820·900px
- 접근성: 스킵링크, `aria-selected`·`aria-expanded`, 44px 이상 터치 영역,
  `prefers-reduced-motion` 대응, 라이브 리전
- 그래프·표는 전부 런타임에 SVG/DOM으로 생성 (이미지·라이브러리 없음)
- 웹폰트는 비동기 로드 — 폰트 CDN이 느려도 페이지 기능이 멈추지 않습니다
- 문자 버튼은 `sms:번호?&body=` 형식으로 iOS·안드로이드 모두에서 내용이 채워집니다
- 로컬 확인:
  ```bash
  python -m http.server 8000
  # http://localhost:8000/plan/
  ```
