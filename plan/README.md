# 머니 플랜 — 관심사 선택형 상품 안내 사이트

또봄(한국청년암협회) 홈페이지와 **완전히 분리된 독립 사이트**입니다.
이 폴더(`plan/`)만 통째로 복사하면 다른 도메인에도 그대로 올라갑니다.
빌드 도구·프레임워크·외부 라이브러리 없이 HTML + CSS + 바닐라 JS로만 되어 있습니다.

주소: `https://nrhoon777.github.io/ddobom-website/plan/`

```
plan/
├─ index.html          허브 — "지금 가장 마음에 걸리는 건?" 3택
├─ cashflow.html       ① 노후 현금흐름  (생활자금형·연금형·거치형)
├─ million.html        ② 소비 습관 → 1억  (역산 / 내 금액)
├─ compound.html       ③ 적금 대신 복리  (적금 세후 vs 이 상품)
└─ assets/
   ├─ data.js     ★ 실제 데이터를 넣는 유일한 파일
   ├─ calc.js       계산 엔진 (건드릴 필요 없음)
   ├─ common.js     공통 UI·차트·상담폼 (건드릴 필요 없음)
   ├─ cashflow.js / million.js / compound.js   페이지별 화면
   └─ style.css     디자인 전체
```

모든 상품 페이지 상단·하단에 **뒤로 가기**가 있습니다. 브라우저 히스토리가 있으면 뒤로,
없으면 허브(`index.html`)로 돌아갑니다.

## 1. 지금 바로 바꿔야 할 것 — `assets/data.js` 맨 위

```js
var CONFIG = {
  consultant: "담당 설계사",
  tel:        "010-0000-0000",
  kakaoUrl:   "http://pf.kakao.com/_카카오채널ID/chat",
  formEndpoint: "",     // ← 여기 (아래 설명)
  email:        ""      // ← 또는 여기
};
```

### 신청 폼을 **내 메일로** 받는 3가지 방법

| 방법 | 설정 | 동작 |
|---|---|---|
| **① Formspree (권장)** | `formEndpoint: "https://formspree.io/f/xxxxxxx"` | 고객이 제출하면 **메일함으로 바로 도착**. 페이지에 메일 주소가 노출되지 않음 |
| ② 메일 앱 | `email: "myname@gmail.com"` | 고객 메일 앱이 열리고 내용이 자동으로 채워짐. 고객이 '보내기'를 눌러야 함 |
| ③ 카카오톡 (현재 기본) | 둘 다 비움 | 신청 내용이 클립보드에 복사되고 카카오톡 채널이 열림 |

> ②는 페이지 소스에 메일 주소가 그대로 남아 **스팸 수집 대상**이 됩니다. ①을 권합니다.
> Formspree 무료 가입 → 폼 생성 → 나오는 주소를 붙여넣으면 끝입니다.

## 2. ★ 실제 상품 데이터를 주실 때 — 이 형식이면 가장 좋습니다

지금 계산에 쓰이는 숫자는 **전부 예시값**입니다. 가입설계서에서 아래 것만 뽑아주시면 그대로 반영합니다.

### (가장 중요) 경과 연차별 **환급률 표**
가입설계서 뒤쪽에 있는 "해지환급금 예시표"를 그대로 옮기면 됩니다.

```js
refund: {
  10: { 3: 78.2, 5: 91.0, 7: 104.5, 10: 118.3, 15: 141.0, 20: 168.5, 30: 240.1 },  // 10년납
  20: { 3: 80.1, 5: 93.4, 7: 106.2, 10: 116.0, 15: 129.5, 20: 146.2, 30: 217.0 }   // 20년납
}
```
- 숫자는 **환급률(%) = 해지환급금 ÷ 그때까지 낸 보험료 × 100**
- 표에 없는 연차는 자동으로 보간하고, 마지막 연차 이후는 공시이율로 연장합니다
- `refund: null` 이면 지금처럼 사업비·이율 모델로 **추정**합니다 (현재 상태)

### 함께 주시면 좋은 것
| 항목 | 예시 | 지금 값 |
|---|---|---|
| 상품 정식 명칭 | ○○생명 (무)△△저축보험 | "노후 현금흐름 플랜" 등 임시 |
| 통화 | 원화 / 달러 | 셋 다 원화 (`currency`) |
| 현재 공시이율 · 최저보증이율 | 4.2% / 2.0% | 4.0% / 2.0% |
| 선택 가능한 납입 기간 | 5·7·10·15·20년 | 상품별로 다름 |
| 연금 전환 조건 | 20년 확정 / 종신형 / 개시 가능 연령 | 20년 확정 |
| 중도인출 한도 | 해지환급금의 50% 등 | 미반영 |
| 즉시 고정 수령 지급률 | 연 4.0% | 4.0% (②에서 사용) |
| 암 진단 납입면제(N15) 조건 | 대상 암 범위, 개시 시점 | 문구만 있고 계산엔 미반영 |

**말로 주셔도 됩니다.** "40세 남자 월 50만원 10년납이면 10년 뒤 환급금 얼마" 식으로 몇 개만 주셔도
그 점들에 맞게 모델을 보정할 수 있습니다.

## 3. 각 페이지가 보여주는 것

### ① `cashflow.html` — 노후 현금흐름
- **생활자금형**: 15·20년 뒤부터 매년 "낸 만큼"(월 납입액 × 12) 꺼내 써도 남은 적립금이 어떻게 되는지.
  개시 후 5·10·15·20년의 누적 인출액·잔여 적립금·환급률을 표와 그래프로.
  꺼내는 금액은 *낸 것의 절반 / 낸 만큼 / 1.5배* 로 바꿔볼 수 있습니다.
- **연금형**: 개시 시점의 적립금 → 20년 확정 월 수령액, 총 수령액
- **거치형**: 10·15·20·30년 뒤 금액과 환급률, 낸 돈을 넘어서는 시점

> 스노볼(꺼내 써도 안 줄어듦)은 **적립금에 붙는 이자 > 매년 인출액** 일 때만 성립합니다.
> 이율 버튼을 최저보증으로 내리면 페이지가 "줄어듭니다"라고 정직하게 말하도록 만들어 두었습니다.

### ② `million.html` — 1억 만들기
- 카페·배달·구독·택시·술자리 슬라이더로 **지금 새는 돈**을 먼저 보여주고, 그 절반을 그대로 납입액에 넣음
- **1억 역산**: 7년납/10년납으로 목표 시점에 1억을 만들려면 매달 얼마 (총 납입액·이자분·하루치까지)
- **내 금액**: 내가 넣는 금액이면 10·15·20년 뒤 얼마, 1억까지 얼마 부족한지,
  그리고 **완납 다음 날부터 원금을 헐지 않고 매월 받는 고정 수령액**

### ③ `compound.html` — 적금 대신 복리
- 같은 금액·같은 기간으로 **은행 적금(단리 + 이자소득세 15.4% 차감)** 과 나란히 비교
- 적금 금리는 슬라이더로, 상품 이율은 버튼으로 바꿔가며 확인
- 5·10·15·20년 시점 비교표와 그래프
- **공정 고지**: 단기(2~3년)에 쓸 돈은 적금이 낫다는 점을 페이지가 직접 말합니다

### 공통 (모든 페이지 하단)
- 특장점 아코디언 — 암 진단 납입면제(N15) · 비과세 · 금융소득종합과세 제외 · 건강보험료 산정 제외 · 상속/이연.
  **각 항목에 주의사항이 같이 붙고, `confirmed:false` 인 항목엔 "확인 필요" 배지가 표시됩니다.**
- 유의사항 (해지 손실 · 이율 변동 · 요건 충족 전제 등)
- 카카오톡 버튼 + 상담 신청 폼 (계산 조건이 자동으로 함께 전달됨)

## 5. 기술 메모

- 반응형 모바일 우선 / 브레이크포인트 620·760·860·900px
- 접근성: 스킵링크, `aria-selected`·`aria-expanded`, 44px 이상 터치 영역,
  `prefers-reduced-motion` 대응, 라이브 리전
- 그래프·표는 전부 **런타임에 SVG/DOM으로 생성** (이미지·라이브러리 없음)
- 웹폰트(Pretendard·고운바탕)는 **비동기 로드**라 폰트 CDN이 느려도 페이지 기능이 멈추지 않습니다
- 로컬 확인:
  ```bash
  python -m http.server 8000
  # http://localhost:8000/plan/
  ```
- 이전 버전(달러 종신·연금 단일 페이지, 환율 30년 차트·FAQ 포함)은 git 히스토리의
  `dollar-life/` 커밋에 남아 있어 필요하면 되살릴 수 있습니다.
